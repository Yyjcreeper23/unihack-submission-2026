# unihack-submission-2026
Repo for our team's submission for UniHack 2026 - HABITMON. This is an application that aims to "gamify" learning skills by providing users with their own collection of monsters to interact with, with learning further skills providing users with special feed that can increase their monsters' size and speed.

Results: 
- Honorable Mention for Best Design (second place among 1000+ participants)
- Honorable Mention for Most Fun Idea (second place among 1000+ participants)

Demo Link (available for desktop and tablet): https://habitmon.life/
